# tictactoe-telegram-bot
Телеграм бот для игры в крестики-нолики с выбором сложности.

Вы играете против бота, первым ходит случайный игрок. Вам доступен потрясающий интерфейс пользователя, выбор сложности, получение статистики.
В боте используются следующие технологии - Python 3.10.6, aiogram 3.29.1, aiosqlite, алгоритм Minimax.
